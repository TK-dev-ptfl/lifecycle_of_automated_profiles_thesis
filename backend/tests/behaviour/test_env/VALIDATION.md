## Not validated here

- **Event provenance** (`isTrusted`, pointer events, click under the cursor, hover before click, text through keys, scrolling follows input, screen/client offsets, movement deltas, coalesced samples) are browser facts, not statistics: they follow from the DOM and Pointer Events specifications and from how CDP injects input. There is no recorded data to tune them on.
- **Time before first action, imprecise aim, pauses to read, uneven wheel timing** have no matching public dataset here. Their thresholds are heuristics; treat them as weaker evidence.

## Caveats

- CMU typists typed one fixed password 400 times, so their rhythm is *more* regular than free text. A check that passes them is conservative for comments.
- SapiMouse is a drag-and-drop task recorded by a desktop app, Iliou a web page; the lab is a feed. Path statistics transfer between tasks only approximately.
- The synthetic bot row uses real human timestamps, so it isolates path shape and velocity profile.
